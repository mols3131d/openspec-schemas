# Distributable Sources

`src/` contains the **canonical sources** of reusable assets created and maintained in this repository for potential distribution to other repositories.

- [schemas/](schemas/) — reusable OpenSpec schemas and their own templates and maintenance documentation.
- [skills/](skills/) — reusable Agent Skills authored in this repository (no Skills have been added yet).

Repository-level guidance, tools and starter scaffolds remain outside `src/`. External Skill dependencies, generated runtime projections and temporary working records are not canonical sources here.

Location under `src/` does not by itself install or publish an asset. Distribution targets and procedures require separate configuration.
