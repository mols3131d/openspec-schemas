# Skills

`src/skills/`는 이 저장소에서 작성해 다른 저장소에 배포할 수 있는 재사용 Agent Skills의 원본 경로다.

- [mols-openspec-customize](mols-openspec-customize/SKILL.md) — OpenSpec 프로필·프로젝트 설정·커스텀 스키마·템플릿의 설계, 유지보수, 실사용 검증과 튜닝.

외부에서 가져오는 Skills와 런타임별 생성 projection은 [Rulesync](../../rulesync.jsonc)로 관리하며 이 디렉터리에 복사하지 않는다. 이 원본 자체는 설치·활성화 증거가 아니다.
